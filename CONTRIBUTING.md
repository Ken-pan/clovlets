# Contributing

Report a broken download or suggest a new subject through GitHub Issues. For artwork changes, include the source, creator, generation method where applicable and a rights statement. Do not upload client files, personal information, third-party logos or artwork without permission.

By submitting artwork you agree to contribute it under this project's CC0 dedication, to the extent you hold the rights. Code contributions use MIT. Keep original assets immutable: publish new revisions and update manifest hashes rather than silently replacing a release. Run npm ci, npm run check, npm test and npm run build before a pull request. Check the gallery at desktop and phone widths after UI changes.
