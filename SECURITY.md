# Security

This project is a static image library and browser gallery. It has no accounts, upload endpoint, analytics, provider credentials or application data store. Hosting providers may keep ordinary access logs. Copying to the clipboard requires a user gesture and browser permission. Images load locally from this repository; browser ZIP downloads are limited to 24 originals to keep memory bounded.

Please report vulnerabilities through GitHub's private vulnerability reporting feature on this repository's Security tab. Do not include credentials, private project files or personal data in public issues. The current release series is supported on a best-effort basis; there is no promised response time.
